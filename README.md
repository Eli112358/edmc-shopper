# EDMC Shopper
Plugin for Elite Dangerous Market Connector to plot an optimal route to shop for commodities.

Weather you're working on colonization, a community goal, missions, or just want to make a profit trading commodities; why not do so as efficiently as possible? That's what this EDMC plugin aims to do by automating as much as possible.
